Abstract

Large-scale pretraining has given rise to robot foundation models, but their behavior is fixed after deployment: they cannot absorb the irregular, ever-changing physical world. Zeva closes this loop with a Causal Interaction Memory that is accumulated online from the robot's own interactions and retrieved at every decision. It extracts the action–state-change causal structure through Visual-Behavioral Dynamics, stores experience on dual timescales (Brief Interaction Trace and Persistent Interaction Memory), and injects a compact memory context into a frozen Cosmos3-based action-generation policy. On RoboCasa365, Zeva reaches 76.8% average success, outperforming strong baselines including Fast-WAM; on a real-world chemical-lab benchmark, it improves from repeated attempts without any gradient update, and a human demonstration can warm-start the same frozen policy through memory alone.

Method

Zeva is built around one idea: the robot should not only execute from pretrained weights; it should remember what its own actions caused, and let that memory guide the next attempt.

Stage 1

Causal Interaction Extraction

Visual-Behavioral Dynamics (VBD) records each executed action and the visual state change it caused, recursively forming a Causal Interaction State and task-phase tokens.

Stage 2

Dual-timescale Interaction Memory

A Brief Interaction Trace keeps within-attempt context; a Persistent Interaction Memory accumulates across attempts with similarity-based merging, preserving reusable action–effect evidence.

Stage 3

Memory-Conditioned Policy

A Memory Context Encoder fuses both memory streams with task/phase information into clean semantic tokens, injected into a frozen Cosmos3 generation split. Only memory updates at deployment.

Post-Deployment Capability Scaling

Zeva improves as it interacts. With all policy parameters frozen, cumulative success rises across repeated attempts on both simulation and real hardware.

Human Demonstrations Warm-Start the Same Frozen Policy

A human physically guides the robot through Balance Weighing; VBD encodes the demonstration into Persistent Interaction Memory. The frozen policy then reproduces the demonstrated approach, grasp, transfer, and placement — no gradient update needed.
